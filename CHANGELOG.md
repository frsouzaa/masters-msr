# Changelog

This changelog records notable changes and releases of the project.

## [1.0.0](https://github.com/frsouzaa/masters-msr/tree/1.0.0) - 2026/10/24

- Initial release of the repository lifecycle analysis pipeline.
- Collects GitHub repository activity and metadata, commit history, and Google
  Trends interest data.
- Aggregates metrics monthly and generates EMA trend summaries, statistical
  tests, correlation tables, and CSV/SVG outputs.
